Замена ESB на слабосвязанную событийную архитектуру приводит к тому, что единый централизованный “мозг” системы исчезает, а логика распределяется по множеству независимых компонентов. Маршрутизация, трансформации, валидация, retry и оркестрация больше не находятся в одном месте, а “размазываются” по API Gateway, сервисам, event-bus, stream processing и workflow-движкам. Бизнес-логика уходит в доменные сервисы, интеграционная — в адаптеры и ACL, а событийный слой становится лишь транспортом без собственной бизнес-логики. В результате система становится более гибкой и масштабируемой, но требует строгих контрактов, наблюдаемости и дисциплины, чтобы избежать хаоса распределённой сложности.
#### Маршрутизация
- Замена ESB HTTP routing - Kong, который обеспечит авторизацию, rate-limiting и routing по различным параметрам запроса.
- В Event Driven слое маршрутизация обеспечена Kafka за счет различных типиков, типов событий и consumer groups.
- Apache Flink использован для маршрутизации на уровне данных.
- Маршрутизация в коде микросервисов.
#### Трансформация
- На входе - API Gateway - валидация запросов
- Мэппинг на уровне микросервисов
- Apache Flink - трансформация данных -агрегация, нормализация
- Нормализация с помощью Apache Kafka Streams - мэппинг, фильтрация, объединение
#### Валидация
- Kong реализует schema-validation
- Валидация на уровне микросервисов - валидация DTO, API вызовов
- Валидация Kafka - валидация схем JSON - типы данных, обязательные поля, версия
- Валидация Apache Flink - выявление аномалий, проверка качества данных.
#### Retry
- Retry на уровне API Gateway - retry по timeout, по HTTP кодам 500
- Retry на уровне микросервисов - API retries, circuit breaker, повторы в бизнес-логике
- Kafka consumer retry topics
- Apache Flink - reprocessing, checkpoint recovery
#### Оркестрация
- Оркестрация на уровне микросервисов - Saga Pattern
- Оркестрация на уровне событий Kafka - реакция на события
- Оркестрация Workflow - Camunda
#### Интеграционная и бизнес-логика
- Реализуется через микросервисы
- Интеграционная логика - через различные адаптеры и инфраструктуру
